# 📱 BRS iOS Client — Мобильное приложение Bar Rating System

Официальный мобильный клиент для платформы **BRS (Bar Rating System)**. Приложение разработано для любителей барной культуры и ценителей крафта. Оно позволяет находить заведения на интерактивной карте, просматривать локальные меню, оценивать напитки и совершать быстрые чекины в барах с помощью сканирования QR-кодов.

## 🧭 Ключевые возможности приложения

*   **📍 Интерактивная карта (MapKit):** Отображение гео-маркеров крафтовых баров в реальном времени с автоматической фильтрацией и привязкой к выбранному городу.
*   **📷 Нативный сканер QR-кодов:** Быстрый чекин в заведении через камеру смартфона. Логика валидации проверяет временной интервал (чекин активен строго 3 часа после сканирования).
*   **🔄 Умное управление сессией:** Автоматический перехват серверных ошибок `401 Unauthorized`. Если токен протух или аккаунт был удален, приложение мгновенно и без зависаний сбрасывает сессию и переключает интерфейс на экран входа.
*   **🌐 Мультиязычность (Локализация):** Полная поддержка динамической смены языка (Русский / English) прямо внутри приложения без необходимости перезапуска.
*   **🔒 Apple Privacy Compliant:** Реализована обязательная функция безвозвратного удаления аккаунта (`DELETE /user/delete-account`) непосредственно из экрана настроек в соответствии с жесткими требованиями гайдлайнов App Store.

## 🛠️ Архитектурный паттерн и Стек технологий

Приложение написано на чистом **Swift 5** с использованием современного декларативного фреймворка **SwiftUI**:

*   **Архитектурный шаблон:** `MVVM` (Model-View-ViewModel) для четкого разделения бизнес-логики и интерфейса.
*   **Реактивное программирование:** `Combine` и свойства `@Published` / `@StateObject` для мгновенного обновления UI при изменении состояний данных.
*   **Сетевой слой:** `URLSession` с использованием современного синтаксиса `Async/Await` для работы с асинхронными API-запросами к Flask-бэкенду.
*   **Локальное хранение:** Глобальный синглтон `AuthManager` на базе `@AppStorage` и `UserDefaults` для безопасного удержания JWT-токенов авторизации и ролевой модели пользователя (`user`, `manager`, `administrator`).
*   **Дизайн:** Кастомная темная премиальная тема интерфейса (Dark Mode по умолчанию) с поддержкой кастомизации подложки карт.

## 🚀 Настройка и Локальный запуск

Приложение готово к запуску внутри симулятора Xcode и тестированию в связке с локальным Docker-окружением бэкенда.

1. Откройте проект в **Xcode** (версии 14.0 или новее).
2. Проверьте конфигурационный файл `APIConfig.swift` — для тестирования в симуляторе базовый URL должен смотреть на локальный Docker-контейнер бэкенда:
   ```swift
   struct APIConfig {
       static let baseURL = "http://127.0.0"
   }
   ```
3. Выберите целевое устройство (например, *iPhone 15* или *iPhone 16*) и нажмите **`Cmd + R`** для сборки и запуска приложения.
4. Для проверки сборки проекта без запуска используйте комбинацию **`Cmd + B`**.
